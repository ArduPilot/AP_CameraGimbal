# MT11 platform images

This directory contains the immutable platform inputs needed by the MT11
firmware builder. `kernel` and `rootfs` were extracted byte-for-byte from the
publicly distributed MT11 V1.0.5 update. Their hashes are recorded in
`SHA256SUMS` and enforced by the package builder.

The root filesystem contains the Linux userspace and SS928V100 kernel modules
needed by the camera hardware. At package time, a temporary copy is rebuilt
with the configured root password. The checked-in image is never modified.

It is mostly a small BusyBox-based userspace, but it also contains the SS928
module loader and hardware modules under `/ko`, startup/network scripts, board
utilities and `/home/product_upgrade`. These are required platform support, so
the image is retained as a whole. The camera application and its assets live
on the separate `/app` partition and are not part of this rootfs image.

`config.json` describes the generated system archive and the deliberately
empty MCU member expected by the stock updater. The application archive,
system archive and outer update ZIP are all generated by the build.
